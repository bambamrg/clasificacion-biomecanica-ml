# Datos

## Dataset utilizado

Este proyecto utiliza el dataset:

**Biomechanical Features of Orthopedic Patients**

Fuente:

[Kaggle - Biomechanical Features of Orthopedic Patients](https://www.kaggle.com/datasets/uciml/biomechanical-features-of-orthopedic-patients)

El dataset contiene mediciones biomecánicas relacionadas con la pelvis y la
columna lumbar. La variable objetivo clasifica los registros como `Normal` o
`Abnormal`.

## Descarga del dataset

Para reproducir el proyecto:

1. Descargar el dataset desde Kaggle.
2. Extraer el archivo CSV.
3. Colocar el archivo dentro de esta carpeta.
4. Utilizar el nombre esperado por el notebook.

El archivo de datos no se incluye en este repositorio porque se obtiene
directamente desde Kaggle.

## Variables predictoras
